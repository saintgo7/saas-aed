# M2 — chat.pamout.com 활용 · 수강생 실습 가이드

> **이 문서는 수강생용입니다.** 단계별로 따라 하면서 각 실습의 프롬프트를 chat.pamout.com에 직접 붙여넣어 보세요.

---

## 시작 전 체크리스트

- [ ] 노트북/태블릿 전원 켜기 + 충전기 연결
- [ ] Wi-Fi 연결 확인 (강사가 화면에 공지)
- [ ] 브라우저(Chrome 권장) 주소창에 `chat.pamout.com` 입력
- [ ] 구글 계정 또는 이메일로 로그인 완료
- [ ] 입력창이 보이는 대화 화면에 도달

---

## 실습 1 — 접속 확인 & 첫 번째 메시지

**목표**: chat.pamout.com에 정상 접속하고 AI와 처음 대화해봅니다.

**소요 시간**: 약 3분

### 단계

**Step 1-1.** 브라우저 주소창에 다음을 입력하고 Enter를 누릅니다.

```
chat.pamout.com
```

**Step 1-2.** 구글 계정 또는 이메일로 로그인합니다.

**Step 1-3.** 화면 아래 입력창에 다음 내용을 **그대로 복사해서** 붙여넣고 Enter(또는 전송 버튼)를 누릅니다.

```
안녕하세요. 저는 자동차 제작 회사에서 일하고 있습니다.
오늘 AI 활용 교육을 받고 있는데, 이 AI가 제 업무에 어떻게 도움을 줄 수 있는지 궁금합니다.
자동차·특장차 업무에서 AI를 활용할 수 있는 사례를 3가지만 간단히 알려주세요.
```

**Step 1-4.** AI의 답변을 읽고 다음을 확인합니다.
- [ ] 답변이 한국어로 나왔는가?
- [ ] 3가지 사례가 나왔는가?
- [ ] 내 업무와 연관된 내용이 있는가?

---

### 기대 결과

AI가 품질 관리, 문서 작성, 데이터 분석 등 자동차·특장차 업무 관련 활용 사례 3가지를 한국어로 설명합니다.

### 더 해보기

> 답변을 읽고 가장 관심 있는 사례에 대해 추가 질문해보세요.
> 예: `"두 번째 사례인 [내용]에 대해 더 자세히 설명해주세요."`

---

## 실습 2 — 역할 부여로 전문가 답변 받기

**목표**: AI에게 '역할(Role)'을 주면 답변의 전문성이 달라지는 것을 체험합니다.

**소요 시간**: 약 5분

### 단계

**Step 2-1.** 먼저 역할 없이 질문해봅니다. 새 대화를 열지 않고 현재 창에서 계속 입력합니다.

```
FMEA가 무엇인지 설명해주세요.
```

**Step 2-2.** 답변을 잠깐 읽어두세요. (스크롤 업으로 나중에 비교 가능)

**Step 2-3.** 이번에는 왼쪽 상단 '새 대화' 버튼을 눌러 새 대화창을 열고, 아래 프롬프트를 입력합니다.

```
당신은 15년 경력의 자동차 품질관리 전문가입니다.
우리 회사 특장차 생산라인의 신입 품질팀원(엔지니어링 비전공)에게
FMEA(고장 모드 및 영향 분석, Failure Mode and Effects Analysis)가 무엇인지,
실무에서 왜 중요한지를 쉬운 말로 설명해주세요.

조건:
- 어려운 영어 약어는 첫 등장 시 한국어 뜻을 괄호로 설명
- 소방차 또는 살수차 사례를 예시로 활용
- 5문단 이내
```

**Step 2-4.** 두 답변을 비교합니다.

- [ ] 전문성/깊이가 달라졌는가?
- [ ] 예시가 현장감 있게 바뀌었는가?
- [ ] 신입 대상 설명으로 더 쉬워졌는가?

---

### 기대 결과

두 번째 프롬프트에서 소방차·살수차를 사례로 들어 FMEA를 설명하는, 실무 현장에서 바로 쓸 수 있는 수준의 답변이 나옵니다.

### 더 해보기

> 역할을 바꿔보세요.
>
> ```
> 당신은 한국교통안전공단 자동차 인증 심사관입니다.
> FMEA 서류 제출 시 심사관이 가장 주의 깊게 보는 항목 5가지를 알려주세요.
> ```

## 실습 3 — 회의록 요약 (요약 패턴)

**목표**: 긴 텍스트를 붙여넣어 핵심만 빠르게 추출합니다.

**소요 시간**: 약 5분

### 단계

**Step 3-1.** 새 대화를 열고 아래 프롬프트 전체를 복사해서 붙여넣습니다.

```
다음 회의록을 읽고 아래 형식으로 요약해주세요.

[출력 형식]
## 회의 요약
- 일시: 
- 참석자:
- 핵심 결정사항: (번호 목록, 각 항목에 담당자와 기한 포함)
- 다음 회의 전 확인 사항:

[회의록 원문]
일시: 2024년 6월 10일 오전 9시 30분
장소: 2층 회의실
참석: 생산팀장 최부장, 품질팀 이대리, 자재팀 박주임, 인증팀 김사원

안건1) 소방차 5호 출고 일정
- 현황: 차체 도장 완료, 소방 장비 장착 80% 완료
- 문제: 방수포 납품 업체 수급 지연 (3일 예상)
- 결정: 이대리가 6/12까지 대체 업체 2곳 견적 받아 보고
- 결정: 출고 예정일 6/15 → 6/18로 조정, 최부장이 거래처에 통보

안건2) 신규 살수차 제원표 인증 서류 제출
- 김사원이 교통안전공단 제출용 서류 목록 6/13까지 취합
- 이번 주 금요일까지 인증팀 내부 검토 후 다음 주 월요일 최종본 제출

안건3) 6월 품질 목표 점검
- 5월 불량률 1.8%, 목표 1.5% 미달
- 원인 분석 박주임이 담당, 6/14 보고
- 7월부터 입고검사 기준 강화 검토 예정

기타: 다음 회의 6/17 오전 9시 예정
```

**Step 3-2.** 답변을 확인합니다.

- [ ] 결정사항이 담당자·기한과 함께 정리되었는가?
- [ ] 중요한 내용이 누락되지 않았는가?
- [ ] 형식이 요청한 대로 나왔는가?

---

### 기대 결과

회의록 원문에서 담당자·기한이 포함된 핵심 결정사항 목록과 다음 회의 전 확인 사항이 깔끔하게 정리됩니다.

### 더 해보기

> 요약 결과를 이메일 형식으로 바꿔달라고 요청해보세요.
>
> ```
> 방금 요약한 내용을 바탕으로, 회의 참석자 전원에게 보낼 '회의 결과 공유' 이메일 초안을 작성해주세요. 제목도 포함해주세요.
> ```

## 실습 4 — 표 만들기 (데이터 정리 패턴)

**목표**: 산발적인 정보를 표 형식으로 깔끔하게 정리합니다.

**소요 시간**: 약 5분

### 단계

**Step 4-1.** 새 대화를 열고 아래 프롬프트를 붙여넣습니다.

```
다음 특장차 종류별 정보를 마크다운 표로 정리해주세요.

[표 열 구성]
차종 | 주요 용도 | 관련 주요 법령 | 인증 난이도(상/중/하) | 인증 담당기관

[정리할 내용]
1. 소방차: 화재 진압·인명 구조, 소방기본법 및 자동차관리법 적용, 인증 절차 복잡
2. 살수차: 도로 먼지 저감·청소, 자동차관리법 기본 적용, 상대적으로 단순
3. 탱크로리: 위험물·액체류 운송, 위험물안전관리법+자동차관리법+산업안전보건법, 매우 복잡
4. 냉동탑차: 신선식품·의약품 운송, ATP협약+식품위생법+자동차관리법, 중간 수준
5. 윙바디: 일반 화물 운송, 자동차관리법, 비교적 단순
6. 카고크레인: 건설자재 운반·적재, 건설기계관리법+자동차관리법, 이중 인증 필요

표 아래에 "* 인증 난이도는 일반적인 기준이며, 세부 사양에 따라 달라질 수 있음" 각주 추가.
```

**Step 4-2.** 표를 확인합니다.

- [ ] 6개 차종이 모두 포함되었는가?
- [ ] 5개 열이 요청대로 나왔는가?
- [ ] 각주가 추가되었는가?

---

### 기대 결과

6개 차종 정보가 5열로 정리된 마크다운 표와 각주가 생성됩니다. 이 표를 그대로 한글/워드/노션에 붙여넣을 수 있습니다.

### 더 해보기

> 표에 열을 추가해달라고 요청해보세요.
>
> ```
> 방금 표에 "주요 검사 항목 (3가지)" 열을 추가해주세요. 각 차종의 핵심 검사 항목 3가지씩.
> ```

## 실습 5 — 문서 초안 작성 (초안 패턴)

**목표**: 5요소(역할·맥락·작업·형식·예시)를 모두 활용해서 실무 문서 초안을 만들어봅니다.

**소요 시간**: 약 7분

### 단계

**Step 5-1.** 새 대화를 열고 아래 프롬프트 중 **내 업무에 가장 가까운 것 하나**를 골라 붙여넣습니다.

---

**[선택 A] 이메일 초안 — 협력사에 납기 지연 통보**

```
[역할] 당신은 특장차 제작 회사의 생산관리팀 담당자입니다.

[맥락] 소방차 납품 일정이 부품 공급 지연으로 인해 당초 예정일(6월 20일)보다
1주일 늦어질 것으로 예상됩니다. 납품처인 [지방자치단체명]에 정중하게 상황을
설명하고 이해를 구해야 합니다.

[작업] 납기 지연을 안내하는 공식 이메일 초안을 작성해주세요.

[형식]
- 제목 포함
- 수신: [담당자명] 귀중
- 본문: 인사 → 상황 설명 → 사과 → 예상 납기일 안내 → 향후 대응 → 마무리
- 톤: 공식적이고 정중하게, 그러나 지나치게 딱딱하지 않게
- 길이: A4 반 페이지 이내

[예시 문체] "~ 드리게 되어 진심으로 사과드립니다. 현재 상황을 상세히 말씀드리자면..."
```

---

**[선택 B] 주간 업무 보고서 초안**

```
[역할] 당신은 자동차 품질팀 주간 보고서 작성 전문가입니다.

[맥락] 이번 주 우리 팀의 주요 업무는 다음과 같습니다:
- 소방차 5호 최종 품질 검사 완료 (결과: 이상 없음)
- 부적합(NCR) 처리 3건: 2건 완료, 1건 진행 중
- 다음 주 탱크로리 입고검사 준비
- 신규 협력사 품질능력평가 서류 검토 중

[작업] 위 내용을 바탕으로 팀장에게 보고할 주간 업무 보고서를 작성해주세요.

[형식]
표 형식 사용. 열: 업무 항목 / 이번 주 진행 현황 / 완료율 / 다음 주 계획
표 아래에 특이사항 2~3줄

[예시 행]
| 소방차 5호 품질검사 | 최종 검사 완료, 출고 승인 | 100% | 출고 후 A/S 이력 관리 |
```

---

**[선택 C] 교육 계획서 목차**

```
[역할] 당신은 기업 교육 기획 전문가입니다.

[맥락] 우리 회사(특장차 제작사)에서 신입 직원 대상 안전교육 프로그램을
새로 만들려고 합니다. 대상은 생산직 신입 사원 20명이며, 3일 과정입니다.

[작업] 3일 과정 안전교육 프로그램 계획서의 목차와 각 챕터 핵심 내용을
작성해주세요.

[형식]
## 1일차 제목
### 1-1. 세션명 (소요시간)
- 주요 내용 3가지
(이하 동일 구조로)

교육 목표, 사전 준비물, 수료 기준도 포함.
```

---

**Step 5-2.** 답변이 나오면 아래 체크리스트로 평가해봅니다.

- [ ] 요청한 형식대로 출력되었는가?
- [ ] 업무 맥락에 맞는 내용인가?
- [ ] 바로 실무에 쓸 수 있는 수준인가? (아니라면 → 실습 6으로)

---

### 기대 결과

실무에 바로 쓸 수 있는 이메일/보고서/계획서 초안이 지정한 형식으로 출력됩니다. 괄호 `[ ]` 부분만 실제 내용으로 채우면 됩니다.

### 더 해보기

> 톤(문체)을 바꿔달라고 요청해보세요.
>
> ```
> 방금 초안을 더 간결하게, 핵심만 담아서 다시 써줘. 전체 길이 절반으로 줄여줘.
> ```

## 실습 6 — 반복 수정(Refine)으로 품질 올리기

**목표**: AI의 초안을 2~3회 수정 지시로 개선하는 Refine 과정을 직접 경험합니다.

**소요 시간**: 약 8분

### 단계

**Step 6-1.** 실습 5에서 만든 초안(또는 새 대화에서 아래 프롬프트로 시작)을 기반으로 수정 작업을 합니다.

새 대화로 시작하는 경우:

```
특장차 품질관리 절차서의 목차를 작성해줘.
챕터는 10개 이내로.
```

**Step 6-2.** 답변을 받으면, **같은 대화창**에서 아래 수정 지시를 입력합니다.

```
감사합니다. 몇 가지 수정 부탁드립니다.

1. 우리 회사는 소방차와 살수차만 제작합니다. 이 두 차종에 특화된 내용을 반영해주세요.
2. 각 챕터 제목 옆에 참조할 관련 법령 또는 기준을 한 줄씩 추가해주세요.
3. 챕터 순서를 "기획 → 설계 → 생산 → 검사 → 인증 → 사후관리" 흐름으로 재정렬해주세요.
```

**Step 6-3.** 2차 수정 결과를 확인하고, 추가로 고치고 싶은 부분에 대해 아래와 유사한 지시를 입력합니다.

```
챕터 5 "완성차 검사"에서 소방차와 살수차의 검사 항목이 어떻게 다른지
간단한 비교 표를 챕터 아래에 추가해주세요.
열: 검사 항목 / 소방차 기준 / 살수차 기준
```

**Step 6-4.** 최종 결과물을 평가합니다.

- [ ] 처음 답변보다 실무에 더 가깝게 개선되었는가?
- [ ] 3차례 수정을 거쳐 원하는 수준에 도달했는가?
- [ ] 이 방식을 내 업무에 적용할 수 있겠는가?

---

### 기대 결과

처음 "목차 써줘" 한 줄로 시작했지만, 2~3회 수정 지시 후 소방차·살수차 특화 법령·비교 표까지 갖춘 실용적인 절차서 목차로 발전합니다.

### 더 해보기

> AI에게 스스로 개선점을 제안하도록 해보세요.
>
> ```
> 이 목차에서 실무 활용성을 높이기 위해 내가 추가로 요청할 수 있는 개선 방향 3가지를 제안해줘.
> ```

## 실습 7 — 할루시네이션 확인하기 (검증 패턴)

**목표**: AI가 틀릴 수 있는 정보를 스스로 경고하도록 유도하고, 검증 방법을 익힙니다.

**소요 시간**: 약 5분

### 단계

**Step 7-1.** 새 대화를 열고 아래 프롬프트를 입력합니다.

```
자동차관리법에서 특장차 자기인증 절차를 규정하는 조항(조·항·호)을 알려주세요.
단, 정확하지 않거나 확인이 필요한 정보는 반드시 "(확인 필요)"로 표시해주세요.
```

**Step 7-2.** AI 답변에서 "(확인 필요)" 표시가 어디에 붙었는지 확인합니다.

**Step 7-3.** 아래 추가 질문으로 검증 요청을 해봅니다.

```
방금 답변에서 법령 조항을 인용했는데, 이 정보의 정확성에 대해 어느 정도 확신하는지,
그리고 검증하려면 어디서 확인하면 되는지 알려주세요.
```

**Step 7-4.** AI 답변을 읽고 확인합니다.

- [ ] AI가 스스로 불확실성을 인정했는가?
- [ ] 검증 방법(국가법령정보센터 등)을 안내했는가?
- [ ] 숫자·법령·날짜는 AI 답변을 그대로 믿으면 안 된다는 것을 체감했는가?

---

### 기대 결과

AI가 법령 조항 번호에 "(확인 필요)" 표시를 달거나, 정확성에 불확신을 표명합니다. 검증처(국가법령정보센터 law.go.kr)를 안내받습니다.

### 더 해보기

> 검증이 필요 없는 영역에서 AI를 최대한 활용해보세요.
>
> ```
> 정확한 법령 조항은 제가 직접 찾겠습니다. 대신 자기인증 절차를 처음 접하는
> 실무자가 이해하기 쉽게, 절차 흐름을 순서도 형식으로 설명해주세요.
> (법령 번호 인용 없이, 업무 흐름 중심으로)
> ```

## 실습 8 — 내 업무 맞춤 프롬프트 만들기 (자유 실습)

**목표**: 오늘 배운 모든 기법을 활용해서 내 실제 업무에 맞는 프롬프트를 직접 완성합니다.

**소요 시간**: 약 7분

### 단계

**Step 8-1.** 아래 템플릿을 복사한 후, `[ ]` 안을 내 실제 업무 내용으로 채워서 입력합니다.

```
[역할] 당신은 [내 업무 분야, 예: 자동차 인증 담당자/품질 관리 전문가/생산기획팀 담당] 입니다.

[맥락] 저는 [회사 유형, 예: 특장차 제작 회사]의 [부서명]에서 근무하고 있으며,
[현재 상황 또는 배경, 예: 다음 달 신규 차종 인증 서류 제출을 앞두고 있습니다].

[작업] [구체적으로 원하는 것, 예: 제출 서류 체크리스트를 작성해주세요 /
이번 주 보고서 초안을 만들어주세요 / 회의 안건 목록을 정리해주세요].

[형식] [원하는 출력 형태, 예: 번호 목록 / 표(열 이름 포함) / 이메일 형식 / A4 1페이지]

[추가 조건] [있다면 작성, 예: 전문 용어는 쉬운 말로 풀어서 / 300자 이내로 / 한국어로]
```

**Step 8-2.** 결과가 나오면 한 가지 이상 수정 지시를 해봅니다.

**Step 8-3.** 최종 결과물을 저장합니다 (대화 이력에 자동 저장됨).
