## 실습 1 — NCR(부적합 보고서) 초안 생성

**예상 소요 시간:** 8~10분  
**활용 패턴:** 초안 생성  
**난이도:** ★☆☆☆☆ (가장 기본 실습)

### 실습 목표

- AI에게 업무 맥락을 주고 문서 초안을 생성하는 기본 패턴을 익힌다.
- 조건(언제·무엇·얼마나)을 명확히 줄수록 결과가 좋아진다는 원리를 체험한다.

### 실습 절차

**Step 1.** chat.pamout.com 접속 후 새 대화 시작

**Step 2.** 아래 프롬프트를 복사해서 그대로 붙여넣기

```
[배경]
나는 특장차 제조사 품질팀 담당자야. 오늘 아침 입고검사 중 부적합을 발견했어.

[불량 내용]
- 부품명: 살수차 살수 노즐 어셈블리
- 공급사: (익명 — A공급사)
- 납품 수량: 50개
- 불량 수량: 7개 (불량률 14%)
- 불량 내용: 노즐 토출 각도 규격(±5°) 초과, 실측 편차 최대 ±9°
- 발견 일시: 20XX년 X월 X일

[요청]
위 내용을 바탕으로 NCR(부적합 보고서) 초안을 한국어로 작성해 줘.

포함 항목:
1. 보고 번호 (임의값 사용)
2. 발생 일시 / 발견 부서 (공란)
3. 부품명 및 사양 (위 내용 사용)
4. 불량 내용 (수치 포함)
5. 불량 수량 / 전체 수량
6. 임시 처리 방향 (격리 보관, A공급사 통보)
7. 근본원인 분석 (공란 — 추후 작성)
8. CAPA 연결 번호 (공란)
9. 작성자 / 승인자 (공란)

형식: 표 구조, A4 1페이지 이내.
하단에 "본 보고서는 AI 초안이며, 최종 내용은 담당자가 검토·확인해야 합니다."를 명기해 줘.
```

**Step 3.** 결과를 받은 뒤 아래 체크리스트 점검

**Step 4.** (선택) 프롬프트를 수정해 자신의 실제 업무 상황(부품명·불량 유형만 변경)으로 재시도

### 기대결과

- 9개 항목이 포함된 표 형식의 NCR 초안
- 공란(근본원인·서명란) 포함 → 담당자가 직접 채울 준비된 양식
- 생성 시간: 30초 이내

### ✅ 체크리스트

```
□ NCR 보고서 형식(표)으로 출력됐는가?
□ 불량 수량·불량률 수치가 프롬프트 내용과 일치하는가?
□ 근본원인 분석 칸이 공란으로 남아 있는가?
□ 하단에 "AI 초안" 안내 문구가 포함됐는가?
□ 실제 회사명·담당자명이 들어가지 않았는가? (보안 확인)
```

### 응용 팁

- 결과가 너무 짧으면 프롬프트 끝에 `"더 자세히, 각 항목을 2~3문장으로 설명해 줘."` 추가
- 표가 아니라 양식지 형태를 원하면 `"표 대신 항목별 줄글 형식으로 작성해 줘."` 변경
- 자신의 담당 부품명·불량 유형으로 바꿔서 반복 시도 권장

## 실습 2 — FMEA 위험 항목 브레인스토밍

**예상 소요 시간:** 10~12분  
**활용 패턴:** 브레인스토밍  
**난이도:** ★★☆☆☆

### 실습 목표

- AI를 '아이디어 자판기'로 활용하는 브레인스토밍 패턴을 익힌다.
- AI 결과를 그대로 쓰는 것이 아니라, 팀 토론의 출발점으로 사용하는 감각을 기른다.

### 실습 절차

**Step 1.** chat.pamout.com에서 새 대화 시작 (이전 대화와 독립)

**Step 2.** 아래 프롬프트를 복사해서 붙여넣기

```
[상황]
나는 특장차 제조사 품질·설계팀 담당자야.
청소차(압축식 쓰레기 수거차량) 신모델의 FMEA(잠재적 고장 형태 및 영향 분석) 초기 단계야.

[요청]
아래 시스템 항목별로 잠재적 고장 형태(Failure Mode)를 브레인스토밍해 줘.

[대상 시스템]
1. 압축 플레이트 유압 구동부
2. 적재함 도어 잠금장치
3. 후진 경보 시스템 (후방 카메라 포함)
4. 적재함 바닥 부식 방지 코팅
5. 운전석 조작 패널 (PTO 제어)

[각 시스템별 출력 형식]
표 형태: 시스템 | 잠재적 고장 형태 | 예상 영향 | 잠재 원인 (설계/제조/운용 구분) | 위험 수준(상/중/하 — 참고용)

시스템당 최소 3개 고장 형태 작성.

[반드시 포함]
표 하단에:
"이 FMEA 브레인스토밍 결과는 AI가 제안한 참고 아이디어입니다.
실제 FMEA의 위험 점수(RPN) 산정과 최종 판정은 담당 엔지니어가 직접 수행해야 합니다.
규정 적합성 최종 판단은 반드시 담당자가 해야 합니다."
```

**Step 3.** 결과 확인 후 아래 추가 프롬프트로 심화 (선택)

```
위 결과에서 위험 수준 '상(高)'으로 표시된 항목만 골라서
각각 단기 예방 조치 아이디어를 1~2가지씩 추가해 줘.
(아이디어 수준이며, 실제 적용 여부는 담당자 판단)
```

**Step 4.** 결과를 보면서 "이 항목은 우리 현장에 맞는가? 빠진 게 있는가?" 개인 메모

### 기대결과

- 5개 시스템 × 3개 이상 = 15개 이상의 고장 형태 아이디어
- 팀 회의 전 출발점 목록 — 경험 많은 엔지니어 없이도 기초 목록 확보
- 위험 수준 '상' 항목에 예방 조치 아이디어까지 포함

### ✅ 체크리스트

```
□ 5개 시스템 모두 결과에 포함됐는가?
□ 각 시스템당 3개 이상 고장 형태가 나왔는가?
□ "설계/제조/운용" 구분이 포함됐는가?
□ FMEA 한계 안내 문구가 포함됐는가?
□ 내 업무 현장에 '빠진 항목' 또는 '맞지 않는 항목'을 메모했는가?
```

### 응용 팁

- 자신이 담당하는 차종(사다리차·소방차·탱크로리 등)으로 시스템 항목 바꿔서 재시도
- "위험 수준 '상' 항목만 추가 심화"처럼 후속 질문(Follow-up)을 이어가는 연습
- AI 목록과 자신의 경험을 비교 → "AI가 못 찾은 것"을 메모해두면 나중에 프롬프트 개선에 활용

## 실습 3 — 작업표준서(WI) 초안 작성

**예상 소요 시간:** 10~12분  
**활용 패턴:** 초안 생성 + 표준화  
**난이도:** ★★☆☆☆

### 실습 목표

- 구두로만 전달되던 작업 절차를 AI를 활용해 문서화하는 패턴을 익힌다.
- 절차형 문서(번호 단계 + 주의사항 구조)를 빠르게 초안화하는 기술을 체험한다.

### 실습 절차

**Step 1.** chat.pamout.com에서 새 대화 시작

**Step 2.** 아래 프롬프트를 복사해서 붙여넣기

```
[배경]
나는 특장차 제조사의 안전관리 또는 생산관리 담당자야.
소방차의 물탱크 탑재 및 고정 작업 표준서(Work Instruction) 초안을 만들어야 해.
현재는 숙련공이 구두로만 전달하고 있어.

[작업 개요]
- 작업명: 소방차 물탱크 차체 탑재 및 고정 볼트 체결 작업
- 대상 장비: 물탱크 용량 3,000 L급, 볼트 체결 방식 (토크 관리 필요)
- 작업 인원: 2인 1조

[포함 항목]
1. 목적 및 적용 범위 (2~3줄)
2. 관련 장비 및 보호구 (PPE 포함)
3. 작업 전 확인 사항 (체크리스트 5개 이상, □ 형식)
4. 작업 절차 (번호 단계, 각 단계에 핵심 안전 주의사항 한 줄 포함)
   - 탱크 이동 전 점검
   - 리프트/크레인 결속
   - 차체 위 안착 및 위치 결정
   - 볼트 가체결 (임시)
   - 토크 렌치 본체결 (규정 토크 공란으로 남길 것)
   - 최종 육안 검사
5. 비정상 상황 대응 (탱크 미정렬, 볼트 이상 체결 2가지)
6. 안전 경고 박스 (⚠️ 형식으로 별도 강조)
7. 작업 후 정리 및 서류 기록

형식: 번호 단계 + 표 혼합. A4 2페이지 분량 목표.

하단에: "본 작업표준서 초안은 AI가 작성한 참고 문서입니다.
실제 적용 전 안전 전문가, 현장 책임자, 관련 법령(산업안전보건법 등) 검토가 필수입니다.
규정 적합성 최종 판단은 담당자 책임입니다."
```

**Step 3.** 결과를 확인하고, 규정 토크 공란에 실제 사양서 값을 채워넣는 시뮬레이션

**Step 4.** (선택) 자신 업무의 다른 작업 절차로 프롬프트를 수정해 재시도

### 기대결과

- 목적부터 비정상 대응까지 갖춘 작업표준서 초안 (7개 항목 포함)
- 안전 경고 박스(⚠️)가 별도 강조된 구조
- 초안 작성 시간: 기존 3~4시간 → 20~30분 (편집·보완 포함)

### ✅ 체크리스트

```
□ 7개 항목 (목적~작업후 정리)이 모두 포함됐는가?
□ 작업 절차가 번호 단계로 나뉘어 있는가?
□ 각 단계에 안전 주의사항이 포함됐는가?
□ 규정 토크 값이 공란으로 처리됐는가? (AI가 임의 수치를 넣었다면 삭제)
□ 안전 경고 박스(⚠️)가 별도 강조됐는가?
□ 하단에 "전문가 검토 필수" 안내 문구가 포함됐는가?
```

### 응용 팁

- 규정 토크 값, 사용 PPE 종류 등 사양서에 의존하는 내용은 AI 결과에서 반드시 직접 수정
- "비정상 상황 대응" 항목은 경험 많은 작업자와 교차 검토 필수
- 작성된 초안을 팀원 2~3명에게 보여주고 "이상한 부분 있냐"고 물어보는 것이 가장 좋은 검증법

## 실습 4 — 인증 제출서류 누락 점검 체크리스트

**예상 소요 시간:** 8~10분  
**활용 패턴:** 체크리스트 생성 + 오류·누락 지적  
**난이도:** ★★★☆☆

### 실습 목표

- AI를 활용해 서류 누락 가능성을 줄이는 체크리스트 생성 패턴을 익힌다.
- AI의 한계(최신 규정 반영 불확실)를 직접 확인하고, 원문 대조의 중요성을 체험한다.

### 실습 절차

**Step 1.** chat.pamout.com에서 새 대화 시작

**Step 2.** 아래 프롬프트를 복사해서 붙여넣기

```
[배경]
나는 특장차 제조사의 인증 담당자야.
윙바디 트럭 자기인증 서류 제출 전 최종 점검 체크리스트를 만들려고 해.

[차량 정보 (가상)]
- 차종: 윙바디 화물 트럭
- 최대 적재량: 5톤 이하
- 특수 장치: 전동식 윙 개폐 장치, 사이드 언더가드

[요청]
자기인증 제출 전 서류 점검 체크리스트를 만들어 줘.

분류:
1. 기본 행정 서류 (신청서, 제작자 정보 등)
2. 안전기준 적합성 시험성적서 (항목별)
3. 제원표 관련 서류
4. 특수 장치 관련 서류 (윙 개폐 장치, 언더가드)
5. 부품 인증 관련 서류

형식: □ [서류명]: [확인 포인트 또는 유효기간 주의사항]
총 25개 이상.

[필수 포함 문구]
체크리스트 상단에:
"이 체크리스트는 AI가 제안한 참고 목록입니다.
실제 자기인증 요건은 국토교통부 고시 및 자동차 안전기준 원문을 기준으로
담당자가 직접 확인해야 합니다.
규정 적합성 최종 판단은 반드시 담당자 책임입니다."
```

**Step 3.** 결과를 확인하고 아래 추가 프롬프트로 비판적 검토 실습

```
위 체크리스트에서 "국토교통부 자동차 안전기준에 따르면 반드시 필요하지만
빠졌을 가능성이 있는 항목"이 있다면 추가 제안해 줘.
단, AI의 제안이 실제 현행 고시와 다를 수 있으므로, 담당자 확인 필수라는 점을 각 항목에 명시해 줘.
```

**Step 4.** 체크리스트를 보면서 "우리 회사에 없는 서류가 있는가?"를 개인 메모

### 기대결과

- 분류별 25개 이상의 서류 점검 항목
- 유효기간·날인 여부 등 실무 포인트 포함
- AI가 "빠졌을 수 있다"고 지적한 추가 항목 → 원문 대조의 출발점

### ✅ 체크리스트

```
□ 5개 분류 모두 항목이 나왔는가?
□ 각 항목이 □ 형식으로 되어 있는가?
□ 체크리스트 상단에 AI 한계 안내 문구가 포함됐는가?
□ AI가 추가 제안한 항목 중 "실제로 우리가 빠뜨릴 수 있는 것"이 있는가?
□ AI가 제안한 항목을 원문(고시) 없이 그대로 믿지 않기로 다짐했는가?
```

### ⚠️ 이 실습에서 특히 강조

AI가 제시한 서류 항목은 어디까지나 참고입니다. 실제 고시는 수시 개정되고, AI의 학습 데이터에는 최신 개정이 반영되지 않을 수 있습니다. **원문 확인 없이 AI 목록만 믿고 서류를 제출하면 보완 요청을 받을 수 있습니다.**

## 실습 5 — 시험성적서 요약 + 내 업무 프롬프트 자유 설계

**예상 소요 시간:** 10~12분 (2파트 운영)  
**활용 패턴:** 요약 추출 → 자유 응용  
**난이도:** ★★★☆☆

### 실습 목표

- 긴 기술 문서(성적서)의 핵심을 AI가 추출·요약하는 패턴을 익힌다.
- 오늘 배운 패턴을 자신의 실제 업무에 직접 적용하는 프롬프트를 스스로 설계한다.

---

### 파트 A — 시험성적서 요약

**Step 1.** chat.pamout.com에서 새 대화 시작

**Step 2.** 아래 프롬프트를 복사해서 붙여넣기 (예시 성적서 텍스트 포함)

```
[상황]
나는 인증 담당자야. 소방차 조향장치 시험성적서에서 핵심 결과를 요약해야 해.
아래는 성적서의 주요 내용을 텍스트로 옮긴 예시야. (실제 성적서가 아닌 연습용 예시)

[예시 성적서 텍스트]
"시험 항목: 최소 회전반경
 기준값: 12.0 m 이하
 측정값: 11.3 m (적합)

 시험 항목: 조향력
 기준값: 최대 페달력 250 N 이하
 측정값: 210 N (적합)

 시험 항목: 핸들 복원력
 기준값: 주행 후 자동 복원 확인
 측정값: 정상 복원 확인 (적합)

 시험 항목: 조향 잠금각
 기준값: 좌우 각 36° 이상
 측정값: 좌 37.2° / 우 37.0° (적합)

 최종 판정: 전 항목 적합 (Passed)"

[요청]
위 내용을 아래 표 형식으로 요약해 줘:

| 시험 항목 | 기준값 | 측정값 | 판정 |
|---|---|---|---|

표 작성 후 하단에:
"이 요약은 AI가 추출한 초안입니다.
원본 성적서와의 일치 여부는 담당자가 직접 확인해야 합니다.
수치 단위(m, N, °)를 원문과 반드시 대조하세요."
```

**Step 3.** 결과를 원본 텍스트와 비교 → 수치·단위 정확도 확인

---

### 파트 B — 내 업무 프롬프트 자유 설계 (심화)

**Step 4.** 아래 빈칸 템플릿을 자신의 업무로 채워서 새로운 프롬프트를 직접 작성

```
[빈칸 채우기 템플릿]

[배경]
나는 _____ 제조사의 _____ (직무) 담당자야.

[업무 상황]
매주/매월 반복되는 _____ 작업을 AI로 도와받고 싶어.
현재 이 작업에 _____ 시간이 걸리고, _____ 이 어렵다.

[AI에게 원하는 것]
아래 형식으로 _____ 을 만들어 줘:
(형식: 표 / 체크리스트 / 단계별 절차 / 초안 문서 / 요약)

[결과물 조건]
- 분량: A4 _____ 페이지 이내
- 형식: _____
- 반드시 포함할 항목: _____

[주의]
실제 _____ 정보(규정 번호, 사양 수치 등)는 담당자가 원문과 대조해야 함을 명기해 줘.
```

**Step 5.** 직접 작성한 프롬프트를 chat.pamout.com에 입력해서 결과 확인

**Step 6.** 옆자리 동료와 프롬프트와 결과를 서로 공유 (1~2분)

### 기대결과

**파트 A:**
- 4개 항목 요약표 (30초 내 생성)
- 수치·단위 오류 여부 직접 확인 체험

**파트 B:**
- 자신만의 실무 프롬프트 1건 완성
- M5 워크숍 "AI 활용 계획서"의 기초 자료

### ✅ 체크리스트

```
[파트 A]
□ 4개 시험 항목 모두 표에 포함됐는가?
□ 수치와 단위가 원본 텍스트와 일치하는가? (직접 대조)
□ "원본 대조 필수" 안내 문구가 포함됐는가?

[파트 B]
□ 빈칸 템플릿을 자신의 실제 업무로 채웠는가?
□ 프롬프트를 chat.pamout.com에 입력하고 결과를 받았는가?
□ 결과가 기대에 미치지 못하면 어떻게 수정했는가? (메모)
□ 동료와 공유했는가?
```
