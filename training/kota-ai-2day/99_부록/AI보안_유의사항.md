# AI 보안 유의사항 — 안전한 AI 활용을 위한 필독 가이드

> **모든 수강생 필독** | 이 문서는 교육 종료 후에도 업무 현장에서 참고용으로 보관하세요.
> AI 도구를 사용하기 전 반드시 이 내용을 숙지하고 소속 부서의 정보보안 정책과 대조하세요.

---

## 1. 절대 입력 금지 원칙 — 4가지 금지 영역

### 1-1. 개인정보

> 개인정보보호법 위반 및 정보 유출 위험

**절대 입력 금지 목록**:
- 임직원·고객의 성명, 주민등록번호, 생년월일
- 전화번호, 이메일 주소, 자택 주소
- 운전면허번호, 여권번호, 사원번호
- 급여·인사 정보, 징계·인사고과 내용
- 의료정보, 건강검진 결과

**대신 이렇게**: 실제 이름 → "담당자 A", 실제 주민번호 → "XXX-XXXXXXX" 처리 후 입력

---

### 1-2. 미공개 인증 자료 및 설계 도면

> 경쟁사 유출 시 회복 불가능한 손해, 공개 전 기술 유출 위험

**절대 입력 금지 목록**:
- 형식승인·자기인증 신청 전 미제출 시험데이터
- 설계 도면(CAD 파일 포함), 부품 배치도, 전기회로도
- 아직 공개되지 않은 신차·신형 모델 사양
- 특허 출원 전 신기술 내용
- 내부 품질 불량 통계, 결함 분석 보고서 원본

**대신 이렇게**: 공개된 법령·기준·고시 자료는 사용 가능. 실습 시 샘플 데이터로 대체

---

### 1-3. 영업비밀

> 부정경쟁방지법상 영업비밀 해당 시 민·형사 책임

**절대 입력 금지 목록**:
- 원가 계산서, 단가표, 견적서 원본
- 고객사 계약 조건, 납품 단가, 특수 조건 계약
- 주요 거래처 명단, 공급망 구성 정보
- 경영 전략, 신규 사업 계획(공표 전)
- 입찰 전략, 원가 분석

**대신 이렇게**: "단가 100만 원" → "단가 X만 원", 거래처명 → "A사", "B사"로 치환

---

### 1-4. 사내 기밀 문서

**절대 입력 금지 목록**:
- 대외비, 기밀, 극비로 분류된 모든 문서
- 이사회·경영위원회 회의자료
- 감사 결과 보고서, 법적 분쟁 관련 서류
- 개인 인사 평가·발령·징계 관련 서류
- 보안 시스템 구성도, 비밀번호·접속 정보

## 2. 사내 정보보안 체크리스트

AI 도구 사용 전 아래 체크리스트를 확인하세요.

### AI 사용 전 확인

- [ ] 입력하려는 내용에 개인정보(이름·번호·주소)가 포함되어 있는가? → 있으면 제거 또는 치환
- [ ] 이 문서는 '대외비' 또는 '기밀'로 분류되어 있는가? → 그렇다면 사용 금지
- [ ] 공개되지 않은 설계 정보·시험 데이터가 포함되어 있는가? → 있으면 사용 금지
- [ ] 영업비밀(원가·계약 조건·거래처)이 포함되어 있는가? → 있으면 치환 또는 사용 금지
- [ ] 내가 사용하려는 AI 서비스의 데이터 처리 방침을 확인했는가?
- [ ] 소속 부서의 AI 사용 허가 범위 내에 있는가?

### AI 결과 활용 전 확인

- [ ] 결과에 사실과 다른 내용(할루시네이션)이 없는지 검증했는가?
- [ ] 결과를 그대로 공식 문서로 사용하기 전 담당자가 검수했는가?
- [ ] AI가 생성한 숫자·날짜·법령 조항은 원본 자료로 재확인했는가?
- [ ] 생성된 결과물의 최종 책임이 AI가 아닌 작성자(나)에게 있음을 인지하고 있는가?

## 3. 할루시네이션(Hallucination) 검증 절차

**할루시네이션이란?** AI가 그럴듯하게 지어내는 오류. 없는 사실을 있는 것처럼, 틀린 수치를 맞는 것처럼 자신감 있게 제시합니다.

### 할루시네이션이 자주 발생하는 영역

| 영역 | 위험 사례 | 대처 방법 |
|---|---|---|
| 법령·기준 조항 | "도로교통법 제○조" 인용이 틀림 | 국가법령정보센터에서 원문 직접 확인 |
| 수치·통계 | 없는 수치를 있는 것처럼 제시 | 공식 통계 원본 대조 |
| 날짜·이력 | 개정 날짜, 시행일 오기 | 관보·고시 원문 확인 |
| 제품 사양 | 차량 사양 수치가 틀림 | 제조사 공식 자료 대조 |
| 기관명·담당자 | 없는 부서·담당자 이름 생성 | 기관 홈페이지 확인 |
| 인용·출처 | 없는 논문·보고서를 있는 것처럼 인용 | 원문 검색으로 실존 여부 확인 |

### 검증 3단계 절차

```
1단계 — 의심하기
   AI 결과를 보고 "이게 맞나?" 의심하는 습관을 기릅니다.
   특히 숫자, 날짜, 법령 조항, 기관명이 나오면 반드시 의심.

2단계 — 출처 확인하기
   AI에게 "이 내용의 출처는 무엇인가요?"라고 물어봅니다.
   출처를 알려주더라도 실제 해당 URL·문서를 열어 내용 확인.

3단계 — 원본 대조하기
   핵심 수치·조항은 국가법령정보센터, 기관 공식 홈페이지,
   사내 공인 자료로 반드시 재확인합니다.
```

### 실무 검증 팁

```
프롬프트에 이 문장을 추가하면 도움이 됩니다:
"확실하지 않은 내용은 '확인 필요'라고 표시해 주세요."
"출처가 있는 정보는 출처를 함께 알려주세요."
"추정 내용과 사실 내용을 구분해서 표시해 주세요."
```

## 4. 저작권 및 책임 소재

### 저작권 관련 유의사항

| 상황 | 유의사항 |
|---|---|
| AI 생성 결과물 저작권 | 현재 법적으로 불분명. AI가 만든 글·이미지의 저작권은 회사/인간 저작자에게 귀속되지 않을 수 있음 |
| 타인 저작물 AI 입력 | 저작권 있는 외부 문서를 허락 없이 입력하면 저작권 침해 가능 |
| AI 결과물 상업적 활용 | 서비스 약관 확인 필수. 상업 용도 허용 여부가 플랜별로 다름 |
| 번역 결과물 | AI 번역 결과도 검토 없이 공식 문서로 사용 시 오역 책임은 사용자에게 있음 |

### 법적 책임 소재

> **AI는 법적 책임을 지지 않습니다. 최종 책임은 항상 사람(사용자·회사)에게 있습니다.**

- AI가 틀린 정보를 제공해 손해가 발생해도 AI 서비스 제공사 책임은 제한적
- 공식 문서, 인증 서류, 법적 효력이 있는 문서에 AI 결과를 그대로 사용 시 모든 책임은 서명자·발행자에게 귀속
- 인사·징계·계약 관련 판단에 AI 결과를 단독 근거로 사용 금지

## 5. AI 결과 사용 시 검수 워크플로우

공식 문서나 보고서에 AI 생성 내용을 포함할 때의 검수 절차

```
[1] AI로 초안 생성
      ↓
[2] 담당자 1차 검토
      - 사실관계 확인 (수치·날짜·법령·기관명)
      - 개인정보·기밀 정보 포함 여부 재확인
      - 문맥·논리 흐름 점검
      ↓
[3] 필요 시 원본 자료 대조
      - 법령: 국가법령정보센터(law.go.kr)
      - 기준: 국토교통부·교통안전공단 공식 자료
      - 수치: 공인 시험기관 성적서 원본
      ↓
[4] 수정 및 보완
      - AI 결과를 기반으로 담당자가 직접 수정·보완
      - "AI 작성 후 담당자 검수" 이력 남기기 권장
      ↓
[5] 결재선 검토 (공식 문서의 경우)
      - 최종 결재자가 내용 확인 후 서명
      ↓
[6] 발행·배포
      - 문서에 AI 생성 여부 표기 여부는 사내 정책에 따름
```

### 문서 유형별 검수 강도

| 문서 유형 | 권장 검수 강도 | 이유 |
|---|---|---|
| 내부 회의 메모·초안 | 낮음 (빠른 확인) | 법적 효력 없는 참고 자료 |
| 팀 내 공유 보고서 | 중간 (주요 수치 확인) | 의사결정에 영향 |
| 경영진 보고서 | 높음 (전항목 검증) | 중요 의사결정 근거 |
| 대외 공문·계약 서류 | 매우 높음 (전문가 검토) | 법적 효력 발생 |
| 인증 신청 서류 | 최고 (반드시 전문가 검토) | 인증 취소·행정 처분 가능 |

## 7. 사고 발생 시 대처 요령

만약 실수로 개인정보·기밀 정보를 AI에 입력했다면:

1. **즉시 해당 대화 삭제** (서비스 내 대화 삭제 기능 사용)
2. **정보보안 담당자에게 즉시 보고** (숨기면 더 큰 문제)
3. **해당 AI 서비스에 데이터 삭제 요청** (각 서비스 고객센터·개인정보 처리방침 참고)
4. **사고 경위서 작성** (언제·어떤 내용·어떤 서비스에·어떻게 처리했는지)
5. **재발 방지 대책 수립** (입력 전 체크리스트 의무화 등)
