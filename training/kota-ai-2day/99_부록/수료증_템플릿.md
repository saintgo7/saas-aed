## 2. 수료증 제작 시 서식 권장 사항

| 항목 | 권장 규격 |
|---|---|
| 용지 | A4 세로 (210 × 297 mm) |
| 여백 | 상하좌우 각 30mm |
| 제목 글꼴 | 궁서체 또는 명조체, 28pt |
| 본문 글꼴 | 맑은 고딕 또는 바탕체, 14~16pt |
| 테두리 | 이중 실선 또는 장식 테두리 |
| 배경 | 연한 수묵화 또는 태극 문양 워터마크 (선택) |
| 직인란 | 60 × 60mm 이상 공간 확보 |
| 인쇄 | 컬러 레이저 인쇄 권장, 용지는 200g/㎡ 이상 |

## 3. 발급 번호 체계

```
형식: [기관코드]-[연도(4자리)]-[과정코드]-[순번(3자리)]

예시: KOTA-2025-AIED-001

- KOTA  : 한국교통안전공단(Korea Transportation Safety Authority)
- 2025  : 발급 연도
- AIED  : AI 교육(AI Education) 과정 코드
- 001   : 해당 연도 과정 내 수료자 순번
```

|---|---|---|---|---|---|---|---|---|---|

## 5. 수료자 명단 엑셀 파일 관리 규칙

```
파일명 형식: KOTA_AI특강_수료자명단_YYYYMM.xlsx

저장 위치(권장):
- 주관 부서 공유 폴더
- 백업: 담당자 PC 로컬 + 클라우드 백업

시트 구성:
- Sheet1: 수료자 전체 명단
- Sheet2: 미수료자 명단 (사유 포함)
- Sheet3: 수료증 발급 이력 (발급일·방법·수령 확인)
```

## 6. 수료증 발급 절차

```
[1] 교육 종료 직전 출석 현황 최종 확인
      → 출석부 대조, 결석 시간 확인
      ↓
[2] 수료 기준 충족 여부 판단
      → 기준: 전체 교육 시간의 80% 이상 출석
      ↓
[3] 수료자 명단 작성
      → 엑셀 양식에 개인 정보·출석일수·수료여부 기재
      ↓
[4] 수료증 개별 제작
      → 한글/Word 템플릿에 개인정보 입력
      → 발급 번호 부여 (명단과 일치)
      ↓
[5] 결재 및 직인 날인
      → 센터장(또는 위임 결재권자) 서명
      → 기관 직인 날인
      ↓
[6] 수료증 배포
      → 현장 배포: 교육 마지막 날 수여식
      → 우편 발송 필요 시: 수령 확인서 동봉
      ↓
[7] 발급 이력 보관
      → 수료자 명단 엑셀 업데이트
      → 수료증 사본(PDF) 5년 이상 보관
```

## 7. 수여식 진행 멘트 예시 (강사용)

```
"지난 [  ]일 동안 바쁜 업무 중에도 열정적으로 참여해 주신
수료생 여러분께 진심으로 감사드립니다.

여러분이 이번 교육에서 배운 AI 도구들은 당장 내일부터
실무에 활용하실 수 있습니다.

수료증은 단순한 종이가 아닙니다.
AI를 두려워하지 않고, 도구로 활용하겠다는 여러분의 다짐을
담은 증서입니다.

앞으로도 AI를 현명하게, 안전하게 활용해
특장차 산업의 발전에 기여해 주시기 바랍니다.

수료를 진심으로 축하드립니다."
```

## 8. 미수료자 안내 문구 예시

출석 부족 등으로 수료 기준을 충족하지 못한 참가자에게 전달하는 안내:

```
안녕하세요, [이름] 님.

이번 「자동차 산업 임직원을 위한 실무형 AI 활용 특강」에 참가해 주셔서 감사합니다.

아쉽게도 교육 출석 기준(전체 시간의 80% 이상)을 충족하지 못하여
이번 과정의 수료증 발급이 어렵게 되었습니다.

출석 현황: [실제 출석 시간] / [전체 교육 시간] (출석률 [  ]%)

수료증이 필요하신 경우, 추후 재교육 일정이 마련될 시 우선 안내해 드리겠습니다.
교육에 참여해 주신 노력에 감사드립니다.

한국교통안전공단 자동차안전연구원 특장차인증센터 드림
```
