## 1. chat.pamout.com vs. Claude vs. Codex — 한눈에 비교

| 비교 항목 | chat.pamout.com | Claude (Anthropic) | Codex (OpenAI) |
|---|---|---|---|
| **주 용도** | 수업 중 기본 실습·대화형 Q&A | 긴 문서 분석·요약·표 생성·에이전트형 작업 | 코드·자동화 스크립트 생성, 반복 업무 자동화 |
| **접속 방법** | 브라우저 → chat.pamout.com | 브라우저 → claude.ai | 브라우저 → chatgpt.com (Codex 탭) 또는 platform.openai.com |
| **파일 업로드** | 제한적 | PDF·Word·Excel·이미지 등 다양 지원 | Python/CSV/코드 파일 등 처리 가능 |
| **한 번에 처리하는 문서 길이** | 보통 | 매우 긺(최대 약 200,000 토큰) | 긴 코드·파일 처리에 특화 |
| **에이전트형 자동화** | 없음 | Projects·Tools 기능으로 자동화 가능 | 코드 실행·파일 생성·반복 작업 자동화 특화 |
| **비개발자 친화도** | ★★★★★ | ★★★★☆ | ★★★☆☆ (개념 이해 필요) |
| **토큰/비용** | 수업 중 무료(chat.pamout.com) | 무료 플랜 있음, 유료 플랜 추가 기능 | 무료 플랜 있음, 유료 플랜 추가 기능 |
| **권장 사용 상황** | 대화·즉석 아이디어·간단 문서 | 보고서 50페이지 요약, 여러 문서 비교, 양식 대량 생성 | 엑셀 데이터 정제, 파일 일괄 처리, 반복 자동화 개념 시연 |

> **한 줄 정리**
> - chat.pamout.com = 빠른 대화형 AI (수업 기본)
> - Claude = 두꺼운 문서를 꼼꼼히 읽어주는 AI 비서
> - Codex = 반복 업무를 코드로 자동화해 주는 AI 조수

## 2. 언제 무엇을 쓰나? — 의사결정 가이드

```
내 작업은?
│
├─ 짧은 대화, 즉석 질문, 간단 초안 작성
│   → chat.pamout.com (수업 중 항상 여기서)
│
├─ 문서가 길거나(20페이지 이상), 여러 파일을 한꺼번에 검토해야 함
│   → Claude
│
├─ 표/엑셀 데이터를 정리·변환·분석해야 함
│   → Claude (파일 업로드) 또는 Codex
│
├─ 같은 양식을 수십 개 반복 생성해야 함
│   → Claude (문서 자동화) 또는 Codex (코드 자동화)
│
└─ 파일 이름 일괄 변경, CSV 일괄 처리 같은 자동화 로직이 필요
    → Codex
```

## 3. 준비 및 접속 안내

### 3-1. Claude 접속

1. 브라우저에서 `https://claude.ai` 접속
2. 이메일로 무료 계정 생성 (Google 계정 연동 가능)
3. 첫 화면의 **채팅 입력창**에 바로 질문 또는 파일 업로드

> **파일 업로드 방법**: 입력창 왼쪽 📎(클립) 아이콘 클릭 → 파일 선택 → 입력창에 질문 입력 후 전송

### 3-2. Codex 접속

1. 브라우저에서 `https://chatgpt.com` 접속
2. OpenAI 계정 로그인 (Google 계정 연동 가능)
3. 왼쪽 메뉴 또는 상단에서 **"Codex"** 또는 **"ChatGPT"** 선택
4. 파일 업로드 아이콘으로 CSV·Excel·텍스트 파일 첨부 후 작업 지시

> **참고**: Codex는 2025년 기준 ChatGPT 인터페이스 내 통합 제공. 별도 앱 없이 chatgpt.com에서 사용 가능.

### 3-3. 사전 안전수칙 — 반드시 확인 후 실습

> ⚠️ **실습 전 필독 — 사내 자료 업로드 정책 확인 사항**

- **개인정보(성명·주민번호·연락처)가 포함된 파일은 절대 업로드 금지**
- **미공개 인증 자료, 시험성적서 원본, 설계 도면, 영업비밀 문서 업로드 금지**
- 실습에는 반드시 **샘플 데이터(가상 수치)** 또는 **공개된 기준·규정 문서** 사용
- 회사 내부 정보보안 정책을 먼저 확인하고, 허용 범위 내 자료만 사용
- AI에 입력된 내용은 서비스 개선 학습에 사용될 수 있음(유료 플랜에서 학습 제외 옵션 선택 가능)
- 결과물은 반드시 담당자가 검수 후 사용 (AI 오류 가능성 항상 존재)

자세한 보안 지침 → **AI보안_유의사항.md** 참조

## 4. 단계별 심화 실습 6선

### 실습 A — 긴 보고서·회의록 Claude로 요약하기

**목표**: 분량이 많아 읽기 부담스러운 문서를 Claude에 올려 핵심만 빠르게 추출한다.

**준비물**: PDF 또는 Word 문서 (20페이지 이상 권장) — 공개 자료 또는 샘플 문서 사용

**단계**:

1. `claude.ai` 접속 후 로그인
2. 입력창의 📎 클릭 → 파일 선택 (PDF/Word)
3. 아래 프롬프트를 복사해 붙여넣고 전송

```
아래 문서를 읽고 다음 형식으로 요약해 주세요.

[요약 형식]
1. 핵심 결론 (3줄 이내)
2. 주요 의제/항목별 요약 (항목당 2~3줄)
3. 후속 조치 필요 사항 (체크리스트 형식)
4. 주요 수치/날짜 (표 형식)

문서 성격: 특장차 품질 회의 회의록
독자: 품질팀 팀장
어조: 간결하고 격식 있는 한국어 보고 문체
```

4. 결과 확인 → "3번 항목을 더 구체적으로 써줘" 등으로 추가 요청

**기대 결과**: A4 20페이지 → 한 화면 요약본. 후속 조치 체크리스트 자동 생성.

**주의점**:
- 기밀 회의록은 업로드하지 말고, 내용을 직접 입력창에 붙여넣는 방식도 가능
- 요약이 부정확하면 "~~ 부분을 다시 읽고 수정해줘" 라고 피드백

### 실습 B — 표·엑셀형 데이터 정리 및 변환

**목표**: 정리되지 않은 텍스트 데이터나 CSV를 Claude에 붙여넣어 깔끔한 표로 변환한다.

**준비물**: 엑셀 또는 CSV 파일, 혹은 아래 예시 데이터를 직접 사용

**단계**:

1. 아래 샘플 데이터를 그대로 복사

```
차량번호 12가3456, 점검일 2025-03-01, 담당자 김철수, AED 배터리 불량, 조치완료
차량번호 34나5678, 점검일 2025-03-02, 담당자 이영희, 패드 교체 필요, 미완료
차량번호 56다7890, 점검일 2025-03-03, 담당자 박민준, 전원 점등 이상, 조치완료
차량번호 78라1234, 점검일 2025-03-05, 담당자 최수진, 정상, 해당없음
```

2. Claude 입력창에 다음 프롬프트와 함께 붙여넣기

```
다음은 현장 점검 기록을 텍스트로 나열한 데이터입니다.
이를 아래 컬럼을 가진 표(Markdown 형식)로 정리해 주세요.

컬럼: 번호 | 차량번호 | 점검일 | 담당자 | 점검 결과 | 조치 여부

추가 요청:
- '미완료' 항목은 행 맨 오른쪽에 ⚠️ 표시
- 점검일 기준 오름차순 정렬
- 전체 건수와 미완료 건수를 표 아래에 요약
```

3. 결과 표를 복사 → Word 또는 한글 문서에 붙여넣기

**기대 결과**: 정렬된 표 + 미완료 하이라이트 + 통계 요약.

**주의점**:
- 실제 차량번호·담당자 개인정보가 담긴 파일은 업로드하지 말 것
- 엑셀 파일 업로드 시 Claude가 직접 파싱 가능 (파일 첨부 후 "표로 정리해줘" 입력)

### 실습 C — 여러 문서 한꺼번에 검토·비교

**목표**: 개정 전·후 안전기준 두 문서, 또는 복수의 시험 결과 보고서를 동시에 올려 차이점을 자동 추출한다.

**준비물**: 비교할 두 개 문서 (또는 아래 텍스트 예시 사용)

**단계**:

1. Claude 입력창에 📎로 두 개 파일 동시 첨부 (또는 아래처럼 직접 텍스트 붙여넣기)

```
[문서 A — 2024년 특장차 안전기준 제3조 발췌]
소방차 제동장치는 주제동장치와 보조제동장치를 모두 갖추어야 하며,
주제동장치는 전 차축에 작동하여야 한다. 최고속도 100km/h 기준 제동거리 기준치 적용.

[문서 B — 2025년 특장차 안전기준 제3조 발췌(개정)]
소방차 제동장치는 주제동장치, 보조제동장치, 비상제동보조장치(AEB)를 모두 갖추어야 하며,
주제동장치는 전 차축에 작동하여야 한다. 최고속도 100km/h 기준 제동거리 기준치 적용.
비상제동보조장치(AEB)는 2025년 1월 1일 이후 제작 차량부터 의무 적용.
```

2. 다음 프롬프트 입력

```
위 문서 A(2024년)와 문서 B(2025년 개정)를 비교 분석해 주세요.

요청 사항:
1. 추가된 내용 (문서 B에만 있는 것)
2. 삭제된 내용 (문서 A에만 있는 것)
3. 변경된 내용 (표현이 바뀐 것)
4. 실무 영향: 우리 회사가 챙겨야 할 변경 포인트 (3가지 이내)

형식: 표 형식으로 정리, 변경 없는 항목은 제외
```

3. 결과 검토 → "4번 실무 영향을 소방차 제조사 입장에서 더 구체적으로 써줘" 추가 요청

**기대 결과**: 변경 사항 비교표 + 실무 대응 포인트 자동 도출.

**주의점**:
- 비공개 내부 도면이나 사내 미공개 기준 문서는 업로드 금지
- 공개된 법령·고시·기준은 업로드 가능

### 실습 D — 반복 문서 양식 자동 생성

**목표**: 매달 반복 작성하는 출장 보고서, 점검 일지, 교육계획서 등의 양식을 Claude로 대량 생성하거나 자동화 템플릿을 만든다.

**준비물**: 없음 (아래 프롬프트 그대로 사용)

**단계**:

1. Claude에 아래 프롬프트 입력

```
특장차 인증센터 품질팀에서 사용할 월간 입고검사 보고서 양식을 만들어 주세요.

[포함할 항목]
- 보고서 제목, 작성일, 작성자, 결재란(팀장/본부장)
- 검사 대상 차량 목록 (번호/차종/제조사/검사일/담당자)
- 항목별 검사 결과 표 (합격/불합격/보류, 비고)
- 주요 부적합(NCR) 발생 현황 요약
- 시정조치(CAPA) 진행 현황
- 다음 달 예정 사항
- 작성 요령 안내 (각 항목 아래에 회색 글씨로)

형식: 한글(HWP) 문서에 바로 붙여넣을 수 있는 Markdown 표 형식
어조: 공문서 수준의 격식체
```

2. 결과 확인 → 필요에 따라 항목 추가/수정 요청

3. **심화**: "이 양식을 기반으로 3월, 4월, 5월 세 달치 빈 양식을 각각 만들어줘" 요청

**기대 결과**: 즉시 사용 가능한 공문서 수준 양식. 월별 복수 양식 일괄 생성.

**주의점**:
- 생성된 양식은 실제 사용 전 소속 부서 기준 양식과 비교 후 검수 필수
- 결재선·직인 위치는 회사 내규에 맞게 수정

### 실습 E — Codex로 간단 자동화 개념 시연

**목표**: 코딩을 몰라도 "이런 반복 작업을 자동화하고 싶다"는 요청을 Codex에 하면 어떻게 되는지 체험한다.

**준비물**: chatgpt.com 계정

**배경 설명 (강사 멘트)**:
> "Codex는 AI가 Python 같은 코드를 대신 짜줍니다. 개발자가 아니어도 '이런 걸 자동화하고 싶다'고 말하면 코드를 만들어 줘요. 코드를 직접 실행할 필요는 없고, 개념을 이해하고 IT 담당자에게 요청서로 전달하는 용도로도 충분히 활용됩니다."

**단계**:

1. chatgpt.com 접속 → 입력창에 아래 프롬프트 입력

```
우리 팀에서 매달 다음과 같은 반복 작업을 합니다:

작업 내용:
- 폴더 안에 있는 점검 사진 파일들의 이름이 제각각임
  (예: IMG_001.jpg, 사진1.jpg, KakaoTalk_Photo.jpg 등)
- 이를 규칙에 맞게 일괄 변경하고 싶음
  (변경 규칙: 점검일_차량번호_순번.jpg → 예: 20250301_12가3456_001.jpg)

이 작업을 자동화하는 Python 코드를 작성해 주세요.
코드를 전혀 모르는 사람도 이해할 수 있도록:
1. 코드 전체
2. 각 줄이 무엇을 하는지 한국어 주석
3. 실행 방법 (단계별 안내)
4. 주의사항
를 함께 제공해 주세요.
```

2. 코드와 설명이 나오면 내용을 살펴보기 (실행은 IT 담당자에게 요청)

3. **추가 실습**: "엑셀 파일에서 특정 컬럼 값을 추출해서 새 파일로 저장하는 코드도 만들어줘" 요청해보기

**기대 결과**: 자동화 코드 + 한국어 주석 설명 + 실행 방법. IT 담당자 요청서로 활용 가능.

### 실습 F — 점검 체크리스트 자동 생성

**목표**: 차량 종류나 점검 항목 기준이 담긴 기준을 설명하면 Claude가 현장용 점검 체크리스트를 자동으로 만들어 준다.

**준비물**: 없음

**단계**:

1. Claude에 아래 프롬프트 입력

```
소방차(펌프소방차 기준) 출고 전 최종 점검 체크리스트를 작성해 주세요.

[요구사항]
- 점검 항목은 다음 분류로 구성: 외관/차체, 소방펌프, 방수노즐/호스, 제동장치, 전기/조명, 무선통신장비, 소화약제 탑재량, 운전석 안전장치
- 각 항목마다: 점검 내용 / 기준값(있는 경우) / 합격□ 불합격□ 보류□ / 비고란
- 현장에서 인쇄해 바로 사용할 수 있는 표 형식
- 하단에 점검자 서명란·점검일·차량번호 기재란 추가
- 총 점검 항목 수는 30~40개

추가: 불합격 시 후속 조치 흐름도(간단한 텍스트 형식)도 만들어 주세요.
```

2. 결과 확인 → "제동장치 항목을 더 세분화해줘", "항목별 점검 주기(일간/주간/월간)도 추가해줘" 등 추가 요청

3. **변형 실습**: "이 체크리스트를 탱크로리 기준으로 바꿔줘" 요청 → 차종별 맞춤 생성 체험

**기대 결과**: 즉시 인쇄 가능한 현장 점검 체크리스트. 차종 변경 시 수분 내 새 버전 생성.

**주의점**:
- AI가 생성한 체크리스트는 관련 법령·사내 기준과 반드시 대조·검수 후 사용
- 법적 의무 점검 항목 누락 여부 전문가 확인 필수
