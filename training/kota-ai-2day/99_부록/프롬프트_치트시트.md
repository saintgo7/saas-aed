## 1. 프롬프트 6요소 공식

좋은 프롬프트는 아래 6개 요소를 포함합니다. 모두 넣을수록 정확한 결과가 나옵니다.

```
[역할] AI가 어떤 전문가처럼 행동해야 하는지
[맥락] 배경 상황, 대상 독자, 사용 목적
[작업] 구체적으로 무엇을 해달라는 것인지
[형식] 표/목록/문단/코드 중 어떤 형태로 출력할지
[예시] 원하는 결과의 샘플 (있으면 강력함)
[제약] 하지 말아야 할 것, 분량, 금지어
```

### 공식 적용 예시

```
[역할] 당신은 특장차 품질관리 전문가입니다.
[맥락] 소방차 제조사의 품질팀이 사용할 문서입니다. 독자는 현장 검사원입니다.
[작업] 아래 입고검사 결과를 분석해 주요 부적합 원인 3가지를 추출해 주세요.
[형식] 원인 / 해당 건수 / 권고 조치를 표 형식으로 정리해 주세요.
[예시] (원인: 볼트 체결 불량, 건수: 5건, 조치: 토크 기준 재확인 교육)
[제약] 전문 용어는 괄호 안에 한국어 풀이를 추가하고, 200자 이내로 간결하게.
```

## 2. 자주 쓰는 프롬프트 패턴 30선

### 요약·정리 패턴

| # | 패턴 | 예시 프롬프트 |
|---|---|---|
| 1 | 핵심 요약 | "다음 내용을 5줄 이내로 핵심만 요약해 주세요." |
| 2 | 항목별 요약 | "아래 회의록을 안건별로 요약하고, 각 안건의 결정 사항을 별도로 표시해 주세요." |
| 3 | 계층 요약 | "경영진용(1페이지), 실무진용(3페이지) 두 가지 버전으로 요약해 주세요." |
| 4 | 후속 조치 추출 | "이 문서에서 후속 조치가 필요한 항목만 뽑아 담당자·기한과 함께 목록으로 만들어 주세요." |
| 5 | 수치/날짜 추출 | "문서에서 날짜, 수치, 규격값만 골라 표로 정리해 주세요." |

### 문서 작성 패턴

| # | 패턴 | 예시 프롬프트 |
|---|---|---|
| 6 | 초안 생성 | "다음 주제로 공문 초안을 작성해 주세요: [주제]. 격식체, A4 1페이지 분량." |
| 7 | 양식 생성 | "월간 출장보고서 양식을 만들어 주세요. 항목: 출장 일시, 목적, 방문 기관, 주요 내용, 성과, 후속 조치." |
| 8 | 어조 변환 | "아래 문장을 더 공식적인 공문서 어조로 바꿔 주세요." |
| 9 | 분량 조절 | "이 내용을 2배로 늘려 구체적으로 써주세요." / "핵심만 남기고 절반으로 줄여주세요." |
| 10 | 구조 재편 | "이 문서를 서론-본론-결론 구조로 재구성해 주세요." |

### 비교·분석 패턴

| # | 패턴 | 예시 프롬프트 |
|---|---|---|
| 11 | 두 문서 비교 | "문서 A와 문서 B를 비교해 추가/삭제/변경 내용을 표로 정리해 주세요." |
| 12 | 장단점 분석 | "아래 제안서의 장점과 단점을 각각 5가지씩 분석해 주세요." |
| 13 | 위험 요소 찾기 | "이 계획서에서 실행 시 발생할 수 있는 리스크를 3가지 제시해 주세요." |
| 14 | 기준 적합성 검토 | "아래 내용이 제시된 안전기준에 부합하는지 항목별로 검토해 주세요." |
| 15 | 우선순위 정렬 | "아래 과제 목록을 긴급도·중요도 기준으로 우선순위를 정해 주세요." |

### 아이디어·기획 패턴

| # | 패턴 | 예시 프롬프트 |
|---|---|---|
| 16 | 브레인스토밍 | "특장차 품질개선을 위한 아이디어를 10가지 제안해 주세요. 실현 가능성 순으로 정렬." |
| 17 | 대안 제시 | "현재 방법 외에 같은 목적을 달성할 수 있는 대안 3가지를 알려주세요." |
| 18 | 계획 수립 | "다음 목표를 달성하기 위한 3개월 추진 계획을 월별로 작성해 주세요: [목표]." |
| 19 | 체크리스트 생성 | "[대상]에 대한 점검 체크리스트를 현장에서 바로 쓸 수 있는 형식으로 30개 항목 작성해 주세요." |
| 20 | 질문 생성 | "이 보고서를 검토할 경영진이 물어볼 법한 예상 질문 5가지와 답변 초안을 만들어 주세요." |

| 22 | 문단 → 표 | "이 텍스트에서 데이터를 추출해 표로 만들어 주세요." |

| 24 | 용어 풀이 | "이 문서의 전문 용어를 비전문가도 이해할 수 있도록 각주 형태로 풀어 주세요." |
| 25 | 이메일 변환 | "이 내용을 대외 발송용 이메일 형식으로 작성해 주세요. 수신: [기관명]." |

|---|---|---|

| 27 | 논리 검토 | "이 주장의 논리적 허점이나 근거가 부족한 부분을 지적해 주세요." |

| 30 | 개선 제안 | "이 문서를 더 설득력 있게 만들기 위한 개선 사항 3가지를 제안해 주세요." |

## 3. 좋은 프롬프트 vs. 나쁜 프롬프트 비교

### 예시 1 — 요약 요청

| 구분 | 프롬프트 |
|---|---|
| ❌ 나쁜 예 | "요약해줘" |
| ✅ 좋은 예 | "다음 회의록을 품질팀 팀장 보고용으로 5줄 이내로 요약하고, 후속 조치 사항은 별도로 체크리스트 형식으로 정리해 주세요." |

**차이**: 목적·독자·분량·형식이 명확하면 결과가 10배 달라집니다.

### 예시 2 — 문서 작성

| 구분 | 프롬프트 |
|---|---|
| ❌ 나쁜 예 | "공문 써줘" |
| ✅ 좋은 예 | "한국교통안전공단 앞으로 발송할 특장차 시험 일정 조율 공문을 작성해 주세요. 내용: 3월 15일 제동시험 예약, 차량 2대(소방차·살수차), 담당자 연락처 포함, 격식체 공문 형식." |

**차이**: 수신처·목적·구체적 내용·어조를 지정하면 수정 없이 바로 쓸 수 있는 초안이 나옵니다.

### 예시 3 — 분석 요청

| 구분 | 프롬프트 |
|---|---|
| ❌ 나쁜 예 | "이거 분석해줘" |
| ✅ 좋은 예 | "아래 입고검사 데이터에서 불합격률이 높은 부품 카테고리 상위 3가지를 찾아 원인 추정과 개선 방향을 함께 제시해 주세요. 표 형식 + 간략한 서술 2~3문장." |

**차이**: 무엇을 분석해서 어떤 형태로 달라는 것인지가 명확해야 합니다.

### 예시 4 — 아이디어 요청

| 구분 | 프롬프트 |
|---|---|
| ❌ 나쁜 예 | "AI 활용 아이디어 알려줘" |
| ✅ 좋은 예 | "특장차 인증센터 품질팀의 입장에서 현재 수작업으로 하고 있는 반복 업무 중 AI로 자동화하면 효과적일 업무 아이디어 5가지를 제안해 주세요. 각 아이디어마다 현재 방식·AI 적용 방식·예상 절감 시간을 함께 써주세요." |

## 4. 반복 수정(Refine) 표현 모음

AI 결과가 마음에 들지 않을 때 쓰는 후속 지시문

### 더 구체적으로 만들 때

```
"[항목명] 부분을 더 구체적으로 풀어써 주세요."
"사례나 예시를 2~3개 추가해 주세요."
"각 항목마다 [추가할 것]도 포함해 주세요."
"더 자세한 수치/근거를 포함해 주세요."
```

### 형식을 바꿀 때

```
"표 형식 대신 번호 목록으로 바꿔 주세요."
"문단 형식으로 다시 써주세요."
"더 짧게, 핵심만 남겨 주세요."
"A4 1페이지 분량에 맞게 압축해 주세요."
```

### 어조·관점을 바꿀 때

```
"더 공식적인 문어체로 바꿔 주세요."
"경영진이 아닌 현장 직원 눈높이로 다시 써주세요."
"긍정적인 표현 위주로 다시 작성해 주세요."
"[특정 산업/직무] 관점에서 다시 써주세요."
```

### 일부만 수정할 때

```
"3번 항목만 다시 써주세요."
"마지막 단락을 더 강한 결론으로 수정해 주세요."
"제목만 5가지 대안을 제시해 주세요."
"표의 마지막 컬럼 내용만 수정해 주세요."
```

### 방향이 완전히 틀렸을 때

```
"원하는 방향이 달랐어요. 다시 설명할게요: [새로운 설명]"
"이번엔 [조건]을 지키면서 처음부터 다시 작성해 주세요."
"이전 결과는 참고하지 말고, 완전히 새로 작성해 주세요."
```

### 결과를 확장할 때

```
"이것을 기반으로 [다음 단계 작업]도 해주세요."
"같은 형식으로 [다른 주제]에 대해서도 작성해 주세요."
"이 초안을 더 발전시켜 최종본을 만들어 주세요."
```

## 5. 프롬프트 길이 가이드

| 작업 유형 | 권장 길이 | 이유 |
|---|---|---|
| 간단한 질문·번역 | 1~3줄 | 맥락이 명확해 짧아도 됨 |
| 문서 초안 작성 | 5~15줄 | 역할·형식·제약 지정 필요 |
| 복잡한 분석·비교 | 10~20줄 | 조건과 기준을 상세히 |
| 대량 양식 자동화 | 15~30줄 | 항목·예시·규칙까지 포함 |

> **팁**: 너무 짧으면 결과가 모호하고, 너무 길면 AI가 일부 조건을 놓칩니다.
> 중요한 조건은 번호 목록으로 나열하면 더 잘 따릅니다.

## 6. 특장차·인증 업무 전용 프롬프트 스타터 모음

바로 복사해서 사용하세요. `[  ]` 부분만 채우면 됩니다.

```
# 자기인증 관련
"자기인증 적합성 검토 보고서 초안을 작성해 주세요.
차량: [차종], 안전기준: [기준 번호], 검토 항목: [항목 나열]"

# 시험성적서 요약
"아래 시험성적서 내용을 요약하고 합격 여부를 판단해 주세요.
판단 기준: [기준값]. 불합격 항목은 볼드체로 표시해 주세요."

# NCR(부적합) 처리
"다음 부적합(NCR) 발생 건에 대한 시정조치(CAPA) 계획서 초안을 작성해 주세요.
부적합 내용: [내용], 발생 부서: [부서], 기한: [기한]"

# 작업표준서 초안
"[공정명] 작업표준서 초안을 작성해 주세요.
포함 항목: 작업 목적, 적용 범위, 필요 공구, 단계별 작업 절차, 안전 주의사항, 검사 기준"

# 회의록 정리
"아래 회의 내용을 공식 회의록 형식으로 정리해 주세요.
회의명: [회의명], 일시: [날짜], 참석자: [명단]
회의 내용: [원문 붙여넣기]"

# 교육계획서
"[교육 주제] 교육계획서를 작성해 주세요.
대상: [대상], 시간: [시간], 강사: [강사], 교육 목표: [목표]"
```
