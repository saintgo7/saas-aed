## 실습 1 — 사업·교육 계획서 초안 만들기

> **목표**: 목차 잡기 → 항목별 지시 → 초안 2개 항목 완성
> **예상 소요**: 20분
> **난이도**: ★★☆☆☆

---

### 1-1단계. 문서 유형과 목차 결정

아래 프롬프트에서 `[  ]` 부분을 내 상황에 맞게 바꿔 입력하세요.

**【기본형】 사업계획서 목차 요청**
```
너는 특장차 제작사(소방차, 살수차, 청소차 전문) 기획팀의 문서 작성 전문가야.
우리 회사는 연간 특장차 약 [300]대를 제작·납품하며, [국내 소방청 및 지자체]에 주로 납품하고 있어.

지금 [내년도 살수차 신규 라인업 출시 사업계획서]를 작성해야 해.
이 계획서의 목차를 6~8개 항목으로 구성해줘.
각 항목 옆에 어떤 내용을 넣어야 하는지 한 줄 설명도 붙여줘.
전체 문서의 독자는 [회사 임원진]이야.
```

**【교육계획서 전용】**
```
너는 자동차 업계 사내 교육 담당자야.
우리 회사는 [특장차 제작 전문 중소기업]으로, 직원 약 [150]명이 근무하고 있어.

[생성형 AI 도구 활용 역량 강화]를 주제로 사내 교육계획서를 작성해야 해.
목차를 6개 항목으로 구성하고, 각 항목에 들어갈 내용을 한 줄씩 설명해줘.
독자는 [인사팀장과 경영진]이야.
```

**기대 결과 예시**
```
[목차 예시 — AI 생성]
1. 추진 배경 및 필요성 — 현 시장 상황과 이번 계획이 필요한 이유
2. 사업 목표 — 정량/정성 목표 명시
3. 추진 전략 및 내용 — 핵심 사업 방향과 실행 방법
4. 추진 일정 — 월별/분기별 로드맵
5. 소요 예산 — 항목별 예산 내역
6. 기대효과 — 사업 완료 후 기대되는 성과
7. 위험 요소 및 대응 방안 — 리스크 분석
8. 결론 및 요청 사항 — 결재 요청
```

**체크리스트**
- [ ] AI가 6~8개 항목의 목차를 생성했는가
- [ ] 각 항목에 한 줄 설명이 붙어 있는가
- [ ] 내 업무와 무관한 항목이 있다면 표시해두었는가 (다음 단계에서 수정)

---

### 1-2단계. 항목 하나씩 내용 작성 지시

목차가 나왔으면 같은 대화창에서 이어서 입력합니다.

**【1번 항목: 추진 배경 및 필요성】**
```
위 목차의 1번 항목 "추진 배경 및 필요성"을 작성해줘.

조건:
- 분량: A4 반쪽(200~300자 내외)
- 문체: 공식 보고서 문체(합니다/입니다 체)
- 내용: 시장 현황, 추진 필요성, 기대 방향을 포함
- 형식: 두괄식 (핵심 문장 먼저, 이유 나중)
- 번호 목록(①②③) 활용
```

**【2번 항목: 사업 목표】**
```
위 목차의 2번 항목 "사업 목표"를 작성해줘.

조건:
- 분량: A4 반쪽
- 정량 목표(숫자)와 정성 목표(방향성)를 구분해서 작성
- 공식 보고서 문체
- 표 형식(목표 구분 / 세부 목표 / 측정 지표) 사용
```

**체크리스트**
- [ ] 2개 항목의 초안이 완성되었는가
- [ ] 내 회사·업무와 무관한 내용이 포함되어 있지는 않은가 (있으면 다음 실습에서 수정)
- [ ] 법령 조문, 수치, 기관명이 포함된 경우 표시해두었는가 (검증 필요)

## 실습 2 — 주간업무보고 자동 요약

> **목표**: 업무 메모를 붙여넣어 주간보고 형식으로 자동 변환
> **예상 소요**: 10분
> **난이도**: ★☆☆☆☆

---

### 2-1단계. 업무 메모를 주간보고로 변환

```
너는 자동차 업계 직장인의 주간업무보고 작성을 도와주는 어시스턴트야.

아래는 내가 이번 주에 한 일들을 메모한 내용이야.
이것을 깔끔한 주간업무보고서 형식으로 정리해줘.

[업무 메모 — 아래에 내용 직접 입력]
- 월요일: 소방차 제원표 초안 검토, 인증팀과 협의
- 화요일: 살수차 시험성적서 관련 외부 시험기관 방문
- 수요일: 신규 차종 FMEA 작업표준서 초안 작성
- 목요일: 주간 회의 참석 (리콜 이슈 논의), 부적합 보고서 1건 작성
- 금요일: 품의서 작성, 출장 보고서 제출 예정

보고서 형식:
- 기간: [2025년 ○월 ○주차]
- 항목: 주요 활동 / 이슈 및 조치 / 다음 주 계획
- 문체: 간결하고 명확한 보고서체
- 분량: A4 반쪽 이내
```

**체크리스트**
- [ ] 업무 메모가 보고서 형식으로 깔끔하게 정리되었는가
- [ ] '이슈 및 조치' 항목이 포함되어 있는가
- [ ] '다음 주 계획'이 자동 추론되어 포함되었는가 (없으면 직접 추가 요청)

---

### 2-2단계. 내 실제 업무로 변환

```
이번에는 내 실제 이번 주 업무로 주간보고를 만들어줘.

[내 정보]
- 소속: [부서명]
- 직책: [직책명]

[이번 주 주요 업무 메모 — 직접 입력]
(여기에 본인의 실제 업무 내용을 간략히 입력)

위와 같은 주간업무보고 형식으로 작성해줘.
단, 개인정보나 기밀 정보는 포함하지 말고 일반화해서 표현해줘.
```

## 실습 3 — 회의록에서 실행항목 자동 추출

> **목표**: 회의 내용 텍스트를 입력하면 실행항목(담당자·기한 포함) 자동 추출
> **예상 소요**: 10분
> **난이도**: ★★☆☆☆

---

### 3-1단계. 회의 내용 실행항목 추출

```
너는 회의록 정리 전문가야.
아래는 특장차 제작사의 품질팀 주간 회의 내용 메모야.
이것을 정식 회의록 형식으로 정리하고,
마지막에 실행항목(Action Item)을 담당자·기한과 함께 표 형식으로 추출해줘.

[회의 메모 — 원본 입력]
일시: 2025년 3월 10일 오후 2시
참석: 품질팀장(김○○), 인증담당(이○○), 생산담당(박○○)
주요 내용:
- 이번 달 살수차 3호기 시험성적서 제출 기한이 15일인데 아직 준비 안 됨. 이○○ 담당자가 13일까지 초안 완성 예정.
- 작년 리콜 건 관련 CAPA 보고서를 이번 달 말까지 공단에 제출해야 함. 박○○ 담당자가 주도.
- 다음 달 신규 카고크레인 자기인증 일정 확인 필요. 다음 주 회의 전 김○○이 일정표 만들어오기로 함.

[회의록 형식]
1. 회의 개요 (일시, 장소, 참석자)
2. 안건별 논의 내용 요약
3. 결정사항
4. 실행항목 표 (항목 / 담당자 / 기한 / 비고)
```

**체크리스트**
- [ ] 회의 개요, 논의 내용, 결정사항, 실행항목 4개 섹션이 모두 생성되었는가
- [ ] 실행항목 표에 담당자와 기한이 명확히 기재되었는가
- [ ] 메모에 없는 내용이 추가되지는 않았는가 (있으면 삭제 또는 확인)

---

### 3-2단계. 추가 작업 — 실행항목 공유 메시지 변환

```
위에서 추출한 실행항목을 팀 단체 채팅방에 공유할 메시지 형식으로 만들어줘.
간결하고 명확하게, 이모지 없이, 50자 이내 서두로 시작해줘.
```

## 실습 4 — 공문·품의서 초안 작성

> **목표**: 공문과 품의서의 공식 형식을 이해하고 AI로 초안 생성
> **예상 소요**: 15분
> **난이도**: ★★★☆☆

---

### 4-1단계. 공문 초안 작성

```
너는 공공기관 및 기업 공문 작성 전문가야.
아래 상황에 맞는 공문 초안을 작성해줘.

[상황]
- 발신: ○○특장차(주) 품질인증팀
- 수신: 한국교통안전공단 자동차안전연구원
- 목적: 살수차 자기인증 관련 시험 일정 협의 요청
- 핵심 내용: 3월 중 시험 일정 조율 요청, 담당자 연락처 안내 요청

[공문 형식 준수]
- 수신/발신 기관명
- 제목
- 본문 (사유·내용·요청사항 순)
- 붙임 문서 목록 (있을 경우)
- 발신일·담당자 서명란
- 공식 문체(합니다/입니다), 경어체
```

**체크리스트**
- [ ] 수신·발신·제목·본문·발신일 항목이 모두 포함되었는가
- [ ] 본문이 '사유-내용-요청사항' 순서로 구성되었는가
- [ ] 경어체(합니다/입니다)가 일관되게 사용되었는가

---

### 4-2단계. 품의서 초안 작성

```
너는 기업 내부 품의서 작성 전문가야.
아래 상황에 맞는 품의서 초안을 작성해줘.

[상황]
- 작성자: 품질팀 ○○○ 대리
- 품의 제목: AI 문서작성 도구 도입 품의
- 품의 내용: 사내 AI 작성 도구(chat.pamout.com 기업 플랜) 1년 구독 요청
- 예상 비용: 연간 [00]만 원 (팀원 10명 기준)
- 필요 이유: 문서 작성 시간 50% 단축, 품질 균일화 기대
- 결재라인: 팀장 → 부장 → 이사

[품의서 형식 준수]
- 제목, 목적, 사유, 내용(세부 사항), 소요 예산, 기대효과, 결재 요청
- 공식 문체
- 표 및 번호 목록 활용
```

**체크리스트**
- [ ] 7개 항목(제목~결재 요청)이 모두 포함되었는가
- [ ] 예산 항목이 명확히 표시되었는가
- [ ] 기대효과가 정량 수치를 포함해 작성되었는가

## 실습 5 — 발표자료 핵심 문안 작성

> **목표**: 발표 슬라이드 제목·본문 문안을 AI로 빠르게 생성
> **예상 소요**: 10분
> **난이도**: ★★☆☆☆

---

### 5-1단계. 발표 슬라이드 구조 기획

```
너는 프레젠테이션 전문가야.
아래 조건으로 발표자료 슬라이드 구성안을 만들어줘.

[발표 주제]: AI 도입으로 특장차 인증 업무를 혁신하는 방법
[발표 대상]: 회사 임원진 및 팀장 (비기술 청중)
[발표 시간]: 10분
[슬라이드 수]: 8~10장

각 슬라이드에 대해 다음을 작성해줘:
- 슬라이드 번호와 제목
- 핵심 bullet 3개 이내
- 강조할 핵심 메시지 한 줄
```

**체크리스트**
- [ ] 8~10장 구성안이 생성되었는가
- [ ] 각 슬라이드에 제목 + 핵심 bullet + 메시지가 있는가
- [ ] 비기술 청중도 이해할 수 있는 용어로 작성되었는가

---

### 5-2단계. 특정 슬라이드 문안 상세 작성

```
위 구성안에서 [3번 슬라이드: 현재 인증 업무의 문제점]의 문안을 상세히 작성해줘.

조건:
- 발표자가 구두 설명할 스피커 노트(2~3문장)도 함께 작성
- 슬라이드 본문은 bullet 3개, 각 10자 이내 (임팩트 있게)
- 비기술 임원도 공감할 수 있는 실제적 문제 묘사
- 특장차/인증 업무 맥락 반영
```

**체크리스트**
- [ ] 슬라이드 본문 bullet이 10자 이내로 작성되었는가
- [ ] 스피커 노트(설명 멘트)가 포함되었는가
- [ ] 실제 업무 상황이 반영된 내용인가

## 실습 6 — 출장보고서 자동 작성

> **목표**: 출장 메모를 바탕으로 공식 출장보고서 초안 생성
> **예상 소요**: 10분
> **난이도**: ★★☆☆☆

---

### 6-1단계. 출장보고서 초안 생성

```
너는 기업 출장보고서 작성 전문가야.
```

## 실습 7 — AI 활용 계획서 개인 초안 완성 (최종 실습)

> **목표**: M3 모듈의 최종 산출물 — 개인별 'AI 활용 계획서 초안' 완성
> **예상 소요**: 15분
> **난이도**: ★★★☆☆

---

### 7-1단계. AI 활용 계획서 목차 설계

```
너는 직장인의 AI 도입 계획서 작성을 도와주는 전문가야.

나는 [자동차/특장차 업계]에서 [품질/인증/기획/생산/경영지원] 업무를 담당하고 있어.
이번 AI 특강을 통해 내 업무에 AI를 도입하는 계획서를 작성하려고 해.

"AI 활용 계획서"의 목차를 5~7개 항목으로 설계해줘.
작성 목적: 팀장 또는 부서장에게 AI 도입의 필요성과 구체적 계획을 보고하기 위함.
독자: [팀장/부장/이사]
```

---

### 7-2단계. 계획서 전체 초안 생성

```
위 목차를 기반으로 나의 "AI 활용 계획서" 전체 초안을 작성해줘.

[내 정보 — 직접 입력]
- 이름: [본인 이름]
- 소속: [부서명]
- 직책: [직책명]
- 주요 담당 업무: [업무 내용 2~3가지]

[AI 활용 예정 업무 — 직접 입력]
1. [업무 1 예: 주간보고 초안 작성]
2. [업무 2 예: 회의록 실행항목 정리]
3. [업무 3 예: 인증 관련 공문 초안 작성]

[작성 조건]
- 문체: 공식 보고서 문체 (합니다/입니다 체)
- 분량: A4 1~2페이지
- 형식: 항목 번호 + 표 혼합 사용
- 반드시 포함: 기대효과(정량 목표), 주의사항(보안·검증)
```

---

### 7-3단계. 검증 체크 요청

```
위에서 작성한 AI 활용 계획서에서
내가 직접 사실 확인이 필요한 부분을 표시해줘.

특히 아래 항목들을 점검해줘:
- 근거 없이 추정된 수치나 통계
- 특정 법령이나 기준 인용 여부
- 기관명이나 제품명이 실제와 다를 수 있는 부분
- AI가 추가한 내용 중 내가 확인하지 않은 부분

결과를 체크리스트 형식으로 만들어줘.
```

### 7-4단계. 최종 다듬기

필요한 경우 아래 조정 프롬프트를 활용하세요.

**톤 조정 — 더 공식적으로**
```
위 계획서 전체를 한 단계 더 공식적인 문체로 수정해줘.
문장 끝을 "~합니다" 형태로 통일하고, 구어체 표현을 제거해줘.
```

**분량 조정 — 압축**
```
위 계획서를 A4 1페이지로 압축해줘.
핵심 내용만 남기고, 반복되는 표현은 제거해줘.
```

**분량 조정 — 확장**
```
위 계획서의 "기대효과" 항목을 현재의 두 배 분량으로 확장해줘.
각 업무별 시간 절감 효과, 품질 향상 효과를 구분해서 구체적으로 써줘.
```

**결론 강화**
```
위 계획서 마지막에 결재권자를 설득하는 강력한 결론 문단을 추가해줘.
핵심 기대효과 요약 + 즉시 시작 가능하다는 메시지 + 결재 요청 문구 포함.
```

**최종 완성 체크리스트**
- [ ] 내 이름·소속·직책이 정확히 기재되었는가
- [ ] 활용 예정 업무 3가지가 구체적으로 명시되었는가
- [ ] 기대효과에 정량 목표(시간, 건수 등)가 포함되었는가
- [ ] 보안·검증 주의사항이 포함되었는가
- [ ] 공식 보고서 문체가 전체적으로 일관되는가
- [ ] 검증 체크리스트의 항목들을 실제로 확인했는가

## 문장 다듬기 응용 프롬프트 모음

작성한 내용을 더 좋게 만들 때 바로 사용하세요.

```

```

**표 → 글 변환**
```
위 표 내용을 자연스러운 단락 형태의 글로 변환해줘.
공식 보고서 문체 유지.
```

**두괄식 변환**
```
위 내용을 두괄식으로 재구성해줘.
핵심 결론을 첫 문장에 배치하고, 근거·설명을 뒤에 배치해줘.
```

**요약문(Executive Summary) 추가**
```
위 내용 앞에 경영진용 요약문을 3~4문장으로 추가해줘.
핵심 목적, 주요 내용, 기대효과만 담아줘.
```

**가독성 향상**
```
위 내용을 더 읽기 쉽게 수정해줘.
긴 문장은 2개로 나누고, 불필요한 중복 표현은 제거해줘.
```

**비전문가용 쉬운 표현**
```
위 내용에서 전문 용어를 일반인도 이해할 수 있는 표현으로 바꿔줘.
기술 용어가 꼭 필요하면 괄호로 간단히 설명을 붙여줘.
```
