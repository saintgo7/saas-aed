# 사전준비 안내

> **과정명**: 자동차 산업 임직원을 위한 실무형 AI 활용 특강 (1박 2일)
> **주관**: 한국교통안전공단 자동차안전연구원 특장차인증센터

---

## 수강생 사전 안내문

> 이 안내문은 교육 참석 전 **반드시** 읽고 준비 사항을 완료해 주십시오.
> 교육 당일 준비가 되어 있지 않은 경우 실습에 참여하기 어려울 수 있습니다.

---

### 1. 노트북·브라우저·Wi-Fi 준비

#### 1-1. 노트북

- **지참 필수**입니다. 교육장에 별도 PC를 제공하지 않습니다.
- 운영체제: **Windows 10 이상** 또는 **macOS 12 이상** 권장
- 배터리: 교육 당일 **완전 충전** 상태로 지참하십시오.
- 충전기: 노트북 충전기를 반드시 함께 지참하십시오 (교육장 멀티탭 제공 예정이나, 개인 충전기 필수).

#### 1-2. 브라우저

- **Google Chrome** 또는 **Microsoft Edge** 최신 버전을 사용하십시오.
- Safari, Internet Explorer는 일부 기능이 정상 동작하지 않을 수 있으므로 비권장합니다.
- 브라우저 업데이트 방법:
  - Chrome: 우측 상단 메뉴(⋮) → **도움말** → **Chrome 정보** → 자동 업데이트 확인
  - Edge: 우측 상단 메뉴(⋯) → **도움말 및 피드백** → **Microsoft Edge 정보** → 자동 업데이트 확인

#### 1-3. Wi-Fi

- 교육장 내 Wi-Fi가 제공됩니다. 접속 정보는 교육 당일 현장에서 안내됩니다.
- **개인 스마트폰 핫스팟을 대비용으로 준비**해 두시길 권장합니다 (네트워크 불안정 시 대비).
- 교육 중 불필요한 스트리밍·대용량 파일 다운로드는 자제해 주십시오 (전체 수강생 네트워크 공유).

### 2. chat.pamout.com 접속 확인 (단계별 절차)

> 이 교육의 **모든 기본 실습**은 chat.pamout.com에서 진행합니다.
> 교육 **전날까지** 아래 단계를 완료하시고, 문제가 있을 경우 담당자에게 미리 연락해 주십시오.

**Step 1. 브라우저 열기**

Chrome 또는 Edge를 실행합니다.

**Step 2. 주소창에 입력**

```
chat.pamout.com
```

주소를 입력하고 Enter를 누릅니다.

**Step 3. 접속 화면 확인**

- 접속이 정상이면 로그인 화면 또는 대화 입력창이 나타납니다.
- "사이트를 찾을 수 없음" 오류가 나타나면 → 인터넷 연결 상태를 확인하거나, 교육 담당자에게 문의하십시오.

**Step 4. 로그인**

- 담당자로부터 계정 정보(이메일·비밀번호 또는 링크)를 사전 수령한 경우 해당 정보로 로그인합니다.
- 계정 정보를 아직 받지 못한 경우: 교육 담당자에게 즉시 문의하십시오.

**Step 5. 간단 입력 테스트**

로그인 후 대화 입력창에 아래 문장을 입력하고 결과가 나타나는지 확인합니다.

```
안녕하세요. 저는 자동차 업무를 담당하고 있습니다. 생성형 AI를 처음 배우려 합니다. 간단히 자기소개 부탁드립니다.
```

- 응답이 정상적으로 출력되면 준비 완료입니다.
- 오류 메시지 또는 무응답이면 담당자에게 스크린샷과 함께 문의하십시오.

**Step 6. 확인 완료 표시**

아래 체크리스트에 표시하고 교육 참석 전 담당자에게 완료 여부를 알려주십시오.

- [ ] chat.pamout.com 접속 성공
- [ ] 로그인 완료
- [ ] 응답 출력 정상 확인

### 5. 심화 실습 도구 사전 준비 (선택 사항)

> 아래 내용은 **선택 사항**입니다. 준비하지 않아도 교육 이수에 전혀 지장이 없습니다.
> 자동화·에이전트형 AI 작업에 관심 있는 분만 사전 준비하십시오.

#### 5-1. Codex (OpenAI 코딩 에이전트)

- **용도**: 반복 문서 자동화, Excel·CSV 데이터 기반 보고서 자동 생성, 업무 자동화 스크립트
- **접속**: [platform.openai.com](https://platform.openai.com) → Codex 기능
- **사전 준비**:
  - OpenAI 계정 생성 (무료 계정으로 체험 가능)
  - 결제 정보 등록 없이도 일부 기능 체험 가능 (자세한 내용은 `99_부록/Codex_실습가이드.md` 참조)
- **참고**: 교육 중 Codex 실습은 시연 위주이며, 직접 실습은 99_부록 가이드를 통해 자율 진행합니다.

#### 5-2. Claude (Anthropic)

- **용도**: 긴 문서(50페이지 이상) 검토·요약·비교, 표·문서 생성, 에이전트형 작업
- **접속**: [claude.ai](https://claude.ai) → 회원가입 후 사용
- **사전 준비**:
  - claude.ai 회원가입 (무료 플랜으로 체험 가능)
  - 이메일 인증 완료
- **참고**: 교육 중 Claude 실습은 시연 위주이며, 직접 실습은 99_부록 가이드를 통해 자율 진행합니다.

> **도구 혼동 주의**: 교육 중 기본 실습은 **chat.pamout.com**으로 통일합니다.
> Codex·Claude는 강사 안내가 있을 때만 사용합니다. 강사 안내 없이 개별 전환하지 마십시오.

### 6. 보안 유의사항 (반드시 숙지)

> 이 항목은 교육 참석 전 반드시 읽고 이해하십시오.
> 위반 시 회사 정보 유출 사고로 이어질 수 있습니다.

#### 6-1. 절대 입력 금지 항목

AI 도구(chat.pamout.com, Codex, Claude 등)에 아래 정보를 **절대 입력하지 마십시오**.

| 금지 항목 | 구체적 예시 |
|---|---|
| **개인정보** | 성명·주민등록번호·연락처·주소·사원번호 등 |
| **미공개 인증자료** | 시험성적서 원본, 인증신청서, 미제출 인증 데이터, 형식승인 내부 검토 문서 |
| **영업비밀** | 제품 설계도면, 원가 정보, 납품 계약 정보, 고객사 정보, 내부 가격표 |
| **미공개 품질 데이터** | 미공개 NCR 내용, 협력사 명단, 불량 통계 원본 데이터 |
| **개인 금융 정보** | 계좌번호, 카드번호 등 일체 |

#### 6-2. 실습 시 안전한 입력 범위

실습 중에는 아래와 같이 **가상 시나리오** 또는 **일반화된 정보**를 사용하십시오.

- 회사명 대신: "A사", "제작사 B", "특장차 제조업체"
- 담당자 이름 대신: "홍길동 팀장" (가상)
- 실제 수치 대신: 가상 수치 또는 공개된 기준치
- 실제 고객사 대신: "고객사 A", "발주처"

#### 6-3. AI 생성 결과물 사용 시 주의사항

- AI가 생성한 내용은 반드시 본인이 검토·검증하십시오.
- 특히 법령·수치·기술기준 관련 내용은 **원문 확인 필수**입니다.
- AI는 최신 법령을 반영하지 못할 수 있으며, 할루시네이션(그럴듯한 오류)이 발생할 수 있습니다.
- AI 생성 결과를 **그대로 공식 문서에 사용하지 마십시오**. 반드시 수정·검토 후 사용하십시오.
